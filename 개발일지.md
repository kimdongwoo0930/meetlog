
백엔드 작업 리스트
1단계 — 프로젝트 기반 설정
 build.gradle — JWT (jjwt), spring-boot-starter-webflux (AI 프록시용) 의존성 추가
 application.properties — MySQL datasource, JPA DDL, JWT secret, AI server URL 설정
 SecurityConfig — CORS, CSRF off, 엔드포인트별 인가 규칙, JWT 필터 등록
2단계 — 도메인 & 엔티티
 User — id, email, password(BCrypt), name, createdAt
 Meeting — id, title, status(SCHEDULED/IN_PROGRESS/COMPLETED), hostUser, participants, startedAt, endedAt
 MeetingMinutes — meeting(1:1), summary, decisions(JSON), nextAgenda(JSON)
 Todo — meeting, text, assignee, done, createdAt
 TranscriptSegment — meeting, speaker, text, startMs, endMs
3단계 — 인증 (Auth)
 JwtUtil — 토큰 생성/검증
 JwtAuthFilter — OncePerRequestFilter
 AuthController — POST /api/auth/register, POST /api/auth/login, POST /api/auth/refresh
 AuthService + UserDetailsServiceImpl
4단계 — 회의 CRUD
 MeetingController — GET/POST /api/meetings, GET/PATCH /api/meetings/{id}
 MeetingService + MeetingRepository
 MinutesController — GET /api/meetings/{id}/minutes
 TodoController — GET /api/meetings/{id}/todos, PATCH /api/todos/{id} (완료 처리)
5단계 — AI 프록시
 AiProxyService — WebClient로 ai-server POST /analyze 호출
 AiController — POST /api/ai/analyze (비동기, SSE 스트리밍 고려)
6단계 — WebSocket (실시간 회의실)
 WebSocketConfig — STOMP + SockJS 설정
 토픽 구조: /topic/meeting/{id}/transcript, /topic/meeting/{id}/analysis
 MeetingRoomController — @MessageMapping 핸들러
7단계 — 음성 업로드
 AudioController — POST /api/meetings/{id}/audio (Multipart, ai-server로 전달)
